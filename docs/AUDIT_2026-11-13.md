# Molla VPN — Repository Audit (2026-11-13)

## Scope and verdict

Reviewed repository `hidooch980/Voice-Ai`, branch `bootstrap/molla-vpn-foundation`, FastAPI account/auth/device routes, SQLite stores, Flutter shell, Ansible role, documentation and GitHub Actions. This is a source/configuration review, not a penetration test, provider review or live VPN test.

**Status: authenticated pilot control-plane foundation; not production-ready and not a usable VPN service.**

The repository includes password/token primitives, SQLite account/session/subscription storage, account-owned device registry, authenticated pilot routes, persistent login throttling, Flutter disconnected-state shell, guarded WireGuard Ansible template, dependency audit, Bandit, CodeQL and Dependabot. The security hardening PR remains subject to merge into `main`.

## Implemented control-plane behavior

- `POST /api/v1/auth/login`, `GET /api/v1/auth/me`, `POST /api/v1/auth/logout`.
- `GET /api/v1/devices`, `POST /api/v1/devices`, `DELETE /api/v1/devices/{device_id}`.
- Auth routes mount only when `MOLLAVPN_TOKEN_SECRET` contains at least 32 bytes; otherwise they remain unavailable.
- Access tokens are short-lived HMAC-SHA256 bearer tokens; only token IDs and expiry are persisted for session revocation.
- Account suspension invalidates sessions.
- Login throttling persists across process restarts: eight failed attempts in five minutes cause a 15-minute block for the email/IP key.
- Accounts are administrator-provisioned only; there is no public registration endpoint.
- Device operations are authenticated and owner-scoped. Enrollment requires active subscription and enforces the account's device limit transactionally.
- Client public keys are stored; private keys are never accepted by the API.
- Device revocation updates registry state only. It does not yet remove the peer from a live WireGuard interface.

## Deliberate gaps and deployment boundaries

- No email verification, public registration, admin bootstrap/management API, MFA, recovery, refresh tokens, key rotation or complete audit pipeline.
- No payment/billing integration or automatic entitlement webhooks.
- No short-lived VPN profile issuance, server catalog or live peer reconciliation.
- No live VPN node, native tunnel adapter or production traffic path exists.
- Protocol descriptors remain disabled; client Connect remains unavailable.
- No Cloudflare zone/Worker/DNS/WAF deployment has been created or verified.
- Ansible provisioning has not been run against a real server; provider firewall, IPv6 and DNS policy remain incomplete.
- Hosting provider, region, budget and expected concurrency remain undecided.

## Governance

- Repository is public. Never commit credentials, private keys, production user data or confidential production endpoints.
- Branch protection and required checks were disabled at last repository inspection.
- Repository license is not selected. Do not copy AGPL-3.0 reference implementation code without an explicit licensing decision.
- Use deployment secrets for signing keys; configure TLS and actual CORS origins before exposing the API.
- SQLite is a pilot storage choice, not a high-availability production database.

## Remaining release gates

1. Add admin bootstrap, verified registration, MFA/recovery, signing-key rotation and structured audit events.
2. Add configuration issuance and server inventory with short-lived, one-time enrollment challenges.
3. Reconcile device add/revoke operations with live WireGuard nodes; prove revoked peers lose traffic.
4. Select and approve hosting provider/region/budget; provision hardened nodes with firewall, IPv6 and DNS policies and rollback.
5. Implement Android native VPN service and WireGuard adapter, then independent iOS, Windows and macOS adapters.
6. Test end-to-end traffic, DNS, IPv4/IPv6 leak, kill-switch, reconnect, roaming, MTU, load and recovery on every platform.
7. Add signed/reproducible releases, SBOM, dependency review, privacy/legal review, billing, monitoring, backup/restore and support.
8. Enable branch protection/required checks, select repository license and review secret-scanning settings.

## Verdict

The control-plane now has an authenticated pilot API when explicitly configured with a deployment secret. It is not a public account service and it does not activate VPN tunnels. Keep all protocols disabled and the Connect action unavailable until live data-plane and security acceptance tests pass.
